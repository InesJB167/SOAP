# 🎓 Sistema de Orientação Acadêmica e Profissional

## 📌 Sobre o Projeto

O Sistema de Orientação Acadêmica e Profissional é uma aplicação desenvolvida para ajudar estudantes do ensino médio a escolherem o curso universitário mais adequado.

Através de um teste vocacional interativo, o sistema analisa o perfil do estudante com base em seus interesses, habilidades e comportamento, apresentando recomendações personalizadas.

---

## 🚀 Funcionalidades

- 👤 Cadastro de estudantes  
- 🎓 Seleção do curso do ensino médio  
- 🧠 Teste vocacional interativo  
- 📊 Cálculo de compatibilidade com cursos universitários  
- 🏆 Exibição dos cursos mais recomendados  
- 📈 Percentagem de afinidade por curso  
- 📚 Visualização de informações dos cursos  

---

## ⚙️ Tecnologias Utilizadas

- 🟨 Frontend: HTML, CSS, JavaScript  
- 🐍 Backend: Python  
- 🗄️ Banco de Dados: MySQL  

---

## 🎯 Objetivo

Auxiliar estudantes na tomada de decisão sobre o seu futuro académico, utilizando tecnologia para fornecer recomendações baseadas no seu perfil.

---

## 📁 Estrutura do Projeto

- `/frontend` → Interface do usuário  
- `/backend` → Lógica do sistema e API  
- `/database` → Scripts e estrutura do banco de dados
